# Swaraj Vecha - AI/ML & Full Stack Engineer Portfolio

A modern, high-performance Neo-Brutalism developer portfolio and content management dashboard built with React 18, TypeScript, Tailwind CSS, Vite, Express, and MongoDB Atlas.

---

## ⚡ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React, Radix UI, Vite
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas with in-memory caching
- **Media Hosting**: Cloudinary API
- **Styling**: Neo-Brutalist design system with custom animations

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Swarajbabu/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
Create a `.env` file in the root directory:
```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
```

### 4. Run Development Server
```bash
# Start frontend
npm run dev

# Start backend API (optional / admin sync)
npm run server
```

### 5. Build for Production
```bash
npm run build
```
